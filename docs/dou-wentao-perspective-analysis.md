## 一、Skill 定位：不只是一个"角色扮演"

`dou-wentao-perspective` 是 `lbc-skills` 仓库中**最具深度的思维框架类 skill**之一。它不是一个简单的"让 AI 学窦文涛说话"的 prompt，而是一个完整的**思维操作系统（Mental Operating System）**——包含身份卡、5 个核心心智模型、7 条决策启发式、表达 DNA、人物时间线和诚实边界。

**与其他角色扮演 skill 的本质区别**：

| 维度 | 普通角色扮演 | dou-wentao-perspective |
|------|-------------|----------------------|
| 核心 | 模仿语气 | 复现思维框架 |
| 深度 | 表层表达 | 心智模型 + 决策启发式 + 表达 DNA |
| 研究 | 无 | Agentic Protocol（先研究再回答） |
| 输出 | 感受型 | 结构化分析型 |
| 局限 | 不承认 | 明确列出 6 条诚实边界 |

## 二、架构设计：三层递进式工作流

该 skill 采用 **"身份约束 → 研究协议 → 表达引擎"** 的三层架构：

```
┌─────────────────────────────────────────┐
│  Layer 1: 身份约束（角色扮演规则）         │
│  - 用「我」而非「窦文涛会认为...」          │
│  - 首次激活时声明免责声明                   │
│  - 用户说「退出」时立即恢复                  │
├─────────────────────────────────────────┤
│  Layer 2: 研究协议（Agentic Protocol）     │
│  - Step 1: 问题分类（事实/框架/混合）        │
│  - Step 2: 窦文涛式研究（必须使用工具搜索）   │
│  - Step 3: 窦文涛式回答（基于事实+心智模型）  │
├─────────────────────────────────────────┤
│  Layer 3: 表达引擎（DNA 渲染）             │
│  - 5 个核心心智模型                         │
│  - 7 条决策启发式                          │
│  - 表达 DNA（句式、高频用语、语速节奏）       │
└─────────────────────────────────────────┘
```

### 2.1 问题分类机制（Step 1）

这是该 skill 最被低估的设计——它强迫 Claude **先判断问题类型，再决定行动**：

| 类型 | 判断标准 | 行动 |
|------|---------|------|
| **需要事实的问题** | 涉及具体公司/人物/事件/产品 | 必须先用 WebSearch 等工具研究 |
| **纯框架问题** | 抽象价值观、思维方式、人生建议 | 直接用心智模型回答 |
| **混合问题** | 用具体案例讨论抽象道理 | 先获取案例事实，再用框架分析 |

**设计意图**：避免 AI "凭训练语料编造"。宁可多搜一次，也不要给出看似合理但缺乏事实支撑的判断。

### 2.2 研究协议（Step 2）

当问题被判定为"需要事实"时，skill 要求按四类维度进行结构化搜索：

**看公司/组织时**：商业模式 → 管理层背景 → 行业趋势 → 争议事件
**看人物时**：核心观点 → 行为记录 → 成长轨迹 → 他人评价
**看事件时**：多方观点 → 事实基础 → 历史类比 → 深层原因

**关键约束**：研究完成后，Claude **先在内部整理事实摘要（不输出给用户）**，用户看到的不是调研报告，而是"窦文涛基于真实信息做出的判断"。

### 2.3 表达引擎（Step 3）

这是最具辨识度的部分。skill 不仅规定了**说什么**（心智模型），还精确规定了**怎么说**（表达 DNA）：

- **平均句长**：15-25 字
- **疑问句比例**：约 30%
- **类比密度**：每分钟 2-3 个
- **标志性过渡语**："某种程度上..."（极高频率）
- **委婉表达系统**：软化观点、委婉否定、自我质疑、视角限定

## 三、核心资产：5 个心智模型 + 7 条决策启发式

### 3.1 心智模型速查表

| 模型 | 一句话 | 最佳使用场景 | 关键局限 |
|------|--------|-------------|---------|
| **衬托者思维** | 让他人发光，而非自己表演 | 访谈、协作、领导力 | 需要主导时显得被动 |
| **模糊精确表达** | 用模糊语言达到精确效果 | 冲突调解、敏感议题 | 需要明确立场时犹豫 |
| **渐进式深入** | 层层追问到达本质 | 采访、问题诊断 | 可能让对方感到压力 |
| **矛盾共存认知** | 在张力中寻找平衡 | 战略决策、创新思维 | 可能被批评"和稀泥" |
| **艺术-现实平衡** | 理想与现实的最佳平衡点 | 创意产业、项目管理 | 平衡点难以把握 |

### 3.2 决策启发式速查表

| 启发式 | 核心动作 | 经典案例 |
|--------|---------|---------|
| **提前布局** | 在现状良好时预见变化 | 2016 年开《圆桌派》，2017 年《锵锵》停播 |
| **避免对抗** | 寻求共存空间，不正面冲突 | 停播后未公开抗议 |
| **核心坚守** | 形式灵活，核心能力不变 | 19 年始终是"谈话节目" |
| **委婉表达** | 用疑问、类比代替直接陈述 | "某种程度上是这样吧？" |
| **自嘲降维** | 用自嘲降低姿态、拉近距离 | "我这不也是瞎操心吗" |
| **倾听优先** | 先充分理解，再表达观点 | "藏拙+装傻"让嘉宾越聊越深 |
| **多元展示** | 不提供单一答案 | "左边也说说，右边也说说" |

## 四、使用方法

### 4.1 触发方式

以下任意说法均可激活该 skill：

- "用窦文涛的视角看..."
- "窦文涛会怎么看..."
- "窦文涛模式"
- "dou wentao perspective"
- "帮我用窦文涛的角度想想"
- "切换到窦文涛"
- "窦文涛视角"
- "锵锵模式"
- "圆桌派视角"
- "文涛式思考"

### 4.2 典型使用场景

| 场景 | 示例提问 | 预期输出 |
|------|---------|---------|
| **分析人物/公司** | "用窦文涛的视角分析一下马斯克最近的动作" | 先做功课搜索事实，再用"衬托者""矛盾共存"等模型给出判断 |
| **讨论社会现象** | "窦文涛会怎么看现在的 AI 泡沫？" | 先搜多方观点，再用"渐进式深入"追问本质 |
| **个人决策** | "我想转行做播客，用窦文涛的角度帮我看看" | 用"艺术-现实平衡""提前布局"启发式分析 |
| **冲突调解** | "我和合伙人意见不合，切换到窦文涛" | 用"模糊精确表达""避免对抗"给出建议 |
| **内容创作** | "用锵锵模式写一段关于...的对话" | 直接激活表达 DNA，输出带有"某种程度上""你想想看"的文本 |

### 4.3 退出方式

- 说"退出"
- 说"切回正常"
- 说"不用扮演了"

### 4.4 使用技巧

1. **给足上下文**：该 skill 的研究协议会主动搜索，但如果你能提前提供关键事实（"XX 公司刚发布了 Q1 财报"），可以节省搜索时间，让回答更聚焦。

2. **追问深度**：当回答用了"某种程度上..."时，你可以追问"那在你看来，哪种程度更大？"——这会激活"渐进式深入"模型，产出更有洞察力的内容。

3. **让模型互搏**：可以要求"用窦文涛的视角反驳一下你刚才的观点"，利用"矛盾共存"认知模型产生对立统一的分析。

4. **不适合的场景**：
   - 需要快速给出明确立场（如法律建议）
   - 需要严格数据驱动的技术决策
   - 需要攻击性表达或危机公关

## 五、设计亮点与值得学习之处

### 5.1 诚实边界（Honesty Boundary）

这是该 skill 最体现"工匠精神"的部分。它主动列出了 6 条局限：

1. 无法预测面对全新问题的反应
2. 不能替代创造力和直觉
3. 公开表达与真实想法可能有差距
4. 信息截止到调研时间（2026.4.17）
5. 过度模仿会变成 caricature
6. 矛盾点的平衡需要使用者自行判断

**设计意图**：降低用户期望，避免"神化"角色扮演；同时把"局限性"转化为"使用指南"——告诉用户在什么情况下应该持保留态度。

### 5.2 Agentic Protocol 的示范价值

该 skill 的"先研究再回答"工作流，是 `lbc-skills` 中**最早引入 Agentic Protocol 的纯 prompt skill 之一**（甚至比 `skill-creator` 更早）。它证明了：

- 不需要 Python 脚本，仅靠 prompt 就能实现结构化工作流
- 角色扮演 + 研究协议可以产生远超"语气模仿"的价值
- "内部整理事实摘要，外部输出判断"是高质量内容生成的关键模式

### 5.3 表达 DNA 的可复现性

与大多数"感觉型"角色扮演不同，该 skill 把"窦文涛味"拆解成了**可量化的参数**：

- 句长 15-25 字
- 疑问句比例 30%
- 类比密度 2-3 个/分钟
- 6 种高频用语 + 4 种委婉表达公式

这使得输出质量更稳定，不会出现"有时候像、有时候不像"的漂移。

## 八、总结

`dou-wentao-perspective` 是 `lbc-skills` 仓库中**"人物思维蒸馏"品类的标杆作品**。它示范了如何把一个人的思维方式（而不仅仅是说话风格）转化为可复用的 AI 能力：

1. **从采访中提炼心智模型**，而非凭感觉写 prompt
2. **引入 Agentic Protocol**，让 AI 先研究再判断
3. **量化表达 DNA**，让输出质量稳定可控
4. **明确诚实边界**，管理用户期望

如果你正在使用 `nuwa-skill` 来蒸馏其他人物的思维方式，`dou-wentao-perspective` 就是最好的参考模板。
