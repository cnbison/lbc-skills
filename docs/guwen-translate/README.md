# guwen-translate · 开发总览

## 定位

古文今解：将用户输入的古文段落用现代语境进行通俗、有趣、有呼吸感的诠释。自动识别典籍来源，调用对应风格指南生成个性化解读；非特定典籍则采用通用文言翻译框架（信达雅三层结构）。
