| 典籍 | 参考文件 | 核心气质 | 核心框架 |
|------|---------|---------|---------|

## 缺口诊断方法论

从三个维度评估待补充经典：

1. **使用频率**：用户实际提问/分享/引用的频率
2. **气质独特性**：与现有 4 部经典+通用文言的重叠度，气质差异越大越优先
3. **通用文言的覆盖盲区**：通用文言（信达雅）能否大致胜任，还是会严重失真

## T1：最优先补充

### 1.《论语》

**为什么必须补**

- **使用频率**：极高。"子曰""三人行""己所不欲"的引用频率绝不亚于"道可道"
- **气质独特性**：《论语》不是玄思，是**日用常行中的修身**；不是独白，是**师徒对话体**
- **通用文言盲区**：信达雅来套《论语》，会把活泼的对话体译成僵硬的格言集，丢失语境、反驳、追问的现场感

**核心框架建议**

- **仁**：不是"善良"，是"在具体关系中对人的恰当回应"
- **礼**：不是"礼貌"，是"让人际互动有节奏、有分寸"
- **学**：不是"学习知识"，是"在日常中持续修正自己"
- **对话体还原**：把"子曰"还原成有语境、有反驳、有追问的现场

**风险**
- 容易变成道德说教
- 容易变成成功学引用大全（"三人行必有我师"→职场鸡汤）

---

### 2.《庄子》

**为什么必须补**

- **使用频率**：极高。"逍遥""齐物""庖丁解牛""庄周梦蝶""无用之用"广为人知
- **气质独特性**：现有 4 部经典中，最接近庄子的是道德经，但两者气质天差地别——老子是冷静的观察者，庄子是**疯狂的梦境制造者**。庄子不是"解释"，是"让你掉进去"
- **通用文言盲区**：信达雅译庄子，会杀死它的**幽默感、荒诞感和解构力**

**核心框架建议**

- **逍遥**：不是"自由"，是"不依赖于任何外在标准的自在"
- **齐物**：不是"平等"，是"消解一切分别心的视角翻转"
- **解构**：庄子永远在拆解常识——有用/无用、大/小、生/死、梦/醒
- **寓言即方法**：不用解释寓言寓意，让寓言自己咬你一口

**风险**
- 最容易沦为"顺其自然"的心灵鸡汤
- "逍遥"被误解为躺平/摆烂

---

## T2：值得补充

### 3.《孙子兵法》

**为什么值得补**

- **使用频率**：高。"知己知彼""不战而屈人之兵""奇正"是极高频引用
- **气质独特性**：填补一个**大气质盲区**。现有 5 部全是人文/宗教/哲学维度，孙子是纯**理性博弈思维**。不是道德说教，不是修身养性，是"在对抗中如何不战而胜"
- **通用文言盲区**：信达雅能译出字面，但译不出其**冷静的策略美学**

**核心框架建议**

- **先胜后战**：打仗之前胜负已定，不是在战场上赢的
- **奇正相生**：常规套路和非常规套路的切换
- **虚实**：力量的分配与感知，不是蛮力是误导
- **全胜**：最高的胜利是不打仗

**风险**
- 容易变成职场权谋、办公室斗争指南
- "三十六计"混淆（非孙子原文，但用户常混为一谈）

---

### 4.《坛经》

**为什么值得补**

- **使用频率**：中高频。"菩提本无树""顿悟""不立文字"广为人知
- **气质独特性**：与《金刚经》形成**完美对照**——金刚是"般若智慧"（破执），坛经是"顿悟法门"（明心见性）。气质从"破"转向"立"，从"渐进"转向"翻转"
- **通用文言盲区**：禅宗的语言风格（机锋、公案、偈语）完全不同于任何现有经典

**核心框架建议**

- **顿悟**：不是积累，是翻转。不是修来的，是见即得的
- **不立文字**：语言的悖论——用语言文字告诉你语言文字不可信
- **无念**：不是不想，是不执着于想
- **自性**：佛性不在远处，在你此刻的觉知中

**风险**
- 容易变成"放空""活在当下"的廉价版本
- 与金刚经区分不清（用户可能混为一谈）

## T3：优先级较低

| 经典 | 分析 | 优先级理由 |
|------|------|-----------|
| 《孟子》 | 气质与论语高度重叠（儒家对话体、修身治国），但"浩然之气""性善论"有其独特性 | 可被论语框架覆盖 70%，独立开发性价比不高 |
| 《楚辞》 | 情感强度和浪漫气质独特（香草美人、天问、招魂），但使用频率偏低 | 小众，且通用文言的"雅"层可部分覆盖 |
| 《史记》 | 史传文学，本质是叙事而非哲思。用户问《史记》通常是问具体篇章/人物 | 不属于 guwen-translate 的核心场景（哲思诠释） |
| 《尚书》 | 使用频率低，文本古奥难读，且多为政治训诰 | 偏离 guwen-translate 的用户场景 |
| 《鬼谷子》/纵横家 | 权谋说服类，与孙子兵法气质近，但用户认知度低 | 可被孙子兵法框架部分覆盖 |
| 《菜根谭》《小窗幽记》 | 明清语录体，处世哲学。气质与道德经/庄子有重叠 | 通用文言+道德经/庄子框架可大致覆盖 |

## 综合建议

| 场景 | 建议 |
|------|------|
| **只补一部** | 《论语》。使用频率最高，气质与现有 4 部最不重叠，通用文言盲区最大 |
| **补两部** | +《庄子》。与老子并称"老庄"但气质迥异，填补"颠覆性寓言叙事"的空白 |
| **补三部** | +《孙子兵法》。填补"理性博弈"维度，让 guwen-translate 从"修身悟道"扩展到"处世决策" |
| **补四部** | +《坛经》。与金刚经形成"渐修 vs 顿悟"的对照，完善佛学维度 |

## 待决策问题

1. **是否统一处理"儒家经典"**？《论语》+《孟子》+《大学》+《中庸》是否共用一套"儒家对话体"框架，还是各自独立？
2. **兵家是否属于 guwen-translate 的范围**？《孙子兵法》的气质偏策略/博弈，与现有"修身悟道"经典差异较大，是否单独做一个子类？
3. **禅宗内部是否需要细分**？《坛经》与《金刚经》用户容易混淆，skill 的典籍识别逻辑是否需要更精确的关键词区分？
