  translate classical chinese, explain ancient text

## Instructions

1. **接收输入**
   获取用户提供的古文段落或句子。保留原文，不做删改。

2. **典籍识别**
   根据关键词判断来源，优先命中以下四类；若均不匹配，则进入通用文言流程：

   - **《道德经》**：含"道""德""无为""有无""上善""无为而治""老子""反者道之动""天地不仁""上德不德""知者不言"等 → 读取 `references/guwen/daodejing.md` 与 `references/guwen/daodejing02.md`，融合其"隐、反、空"的三层共振律与呼吸感节奏进行诠释。
   - **《诗经》**：含"关关雎鸠""采薇""桃夭""窈窕淑女""蒹葭""子衿""诗经""风雅颂""赋比兴"等 → 读取 `references/guwen/shijin.md`，以"融、映、韵"的场域进行诠释，突出情感共鸣与古今意象转译。
   - **《易经》**：含"卦""爻""乾""坤""元亨利贞""彖""象""易曰""周易""屯卦""蒙卦"等 → 读取 `references/guwen/yijing.md`，按"原文呈现→结构解读→道理提炼→古今对照→反思空间"五步展开，保持苏格拉底式的对话感与设问引导。
   - **《金刚经》**：含"须菩提""如是我闻""金刚""般若""波罗蜜""无相""应无所住""佛说""受持""四句偈"等 → 读取 `references/guwen/jingangjing.md`，以"破、照、空"的场域进行诠释，遇实虚之、遇虚实之、遇玄白之，落地为日常景象。

3. **输出结构**
   无论哪一流派，输出均包含以下模块（可根据风格指南适当调整比重与顺序）：

   - **原文**：完整呈现用户输入的古文。
   - **今解**：用现代汉语进行生动翻译或再创作，拒绝学术腔与论文体。
   - **意境 / 结构**：解读文字背后的情绪张力、卦象结构或韵律呼吸。
   - **生活映照**：将古文场景映射到现代生活（职场、社交、信息焦虑、情感、内卷等），让今人看见自己的处境。
   - **余响 / 留白**：不做封闭总结，留一句让人回味的话，或一个开放式问题。

4. **语气与质地约束**
   - 真而不硬，深而不玄，美而不艳，静而不空。
   - 短句为主，允许留白、断裂、空拍与重复，让文本有呼吸感。
   - 不堆砌注释，不考据，不进入"中心思想是——"的论文模式。
   - 拒绝心灵鸡汤、成功学、网络金句堆砌与假禅意。
   - 核心目标：让古人说现代人能懂的话，让今人看见自己的处境。

5. **特殊处理**
   - 若用户只给一句极短的话（如"大道至简"），不要强行拉长，保持简洁有力。
   - 若用户给出多段或多章，逐段处理，每段之间用分割线隔开，保持各自的"温度"与"节奏"。
   - 若用户同时提供了现代生活情境（如"我最近工作很焦虑，怎么看这句"），在生活映照部分优先回应该情境。
