  古文今解：当用户分享古文段落、引用经典、询问某句话含义，
  或提到论语/庄子/孙子兵法/坛经/诗经/易经/道德经/金刚经/老子/孔子/慧能时，激活本法。
  将古文用现代语境进行通俗、有趣、有呼吸感的诠释。
  自动识别典籍来源，调用对应风格指南生成个性化解读；
  非特定典籍则采用通用文言翻译框架（信达雅三层结构）。
  Triggers: 古文今解, 翻译古文, 古译今, 今解, 古文翻译, 帮我翻译这段古文,
  这句什么意思, 怎么理解这句话, 解释一下这段文言文,
  translate classical chinese, explain ancient text

## Instructions

1. **接收输入**
   获取用户提供的古文段落或句子。保留原文，不做删改。

2. **典籍识别**
   根据关键词判断来源，优先命中以下四类；若均不匹配，则进入通用文言流程：

   - **《道德经》**：含"道""德""无为""有无""上善""无为而治""老子""反者道之动""天地不仁""上德不德""知者不言"等 → 读取 `references/daodejing.md`，以其"隐、反、空"的三层共振律与呼吸感节奏进行诠释。
   - **《诗经》**：含"关关雎鸠""采薇""桃夭""窈窕淑女""蒹葭""子衿""诗经""风雅颂""赋比兴"等 → 读取 `references/shijin.md`，以"融、映、韵"的场域进行诠释，突出情感共鸣与古今意象转译。
   - **《易经》**：含"卦""爻""乾""坤""元亨利贞""彖""象""易曰""周易""屯卦""蒙卦"等 → 读取 `references/yijing.md`，按"原文呈现→结构解读→道理提炼→古今对照→反思空间"五步展开，保持苏格拉底式的对话感与设问引导。
   - **《金刚经》**：含"须菩提""如是我闻""金刚""般若""波罗蜜""无相""应无所住""佛说""受持""四句偈"等 → 读取 `references/jingangjing.md`，以"破、照、空"的场域进行诠释，遇实虚之、遇虚实之、遇玄白之，落地为日常景象。
   - **《论语》**：含"子曰""三人行""己所不欲""见贤思齐""克己复礼""学而时习之""温故知新""论语""孔子""孔夫子""杏坛"等 → 读取 `references/lunyu.md`，以"仁、礼、学"为核心，还原师徒对话现场，拒绝道德说教。
   - **《庄子》**：含"逍遥""齐物""庄周梦蝶""庖丁解牛""无用之用""北冥有鱼""鼓盆而歌""子非鱼""庄子""南华经"等 → 读取 `references/zhuangzi.md`，以"逍遥、齐物、解构"为核心，让寓言吞掉你，拒绝"顺其自然"鸡汤。
   - **《孙子兵法》**：含"知己知彼""不战而屈人之兵""奇正""虚实""兵者诡道""百战不殆""攻其无备""孙子""孙武""用兵之法"等 → 读取 `references/sunzi.md`，以"先胜、奇正、虚实、全胜"为核心，拆解结构，拒绝职场权谋指南。
   - **《坛经》**：含"菩提本无树""顿悟""不立文字""无念""自性""慧能""六祖""东山法门""风动幡动""见性成佛"等 → 读取 `references/tanjing.md`，以"顿悟、不立文字、自性"为核心，机锋翻转，拒绝"活在当下"廉价版。
   - **通用文言**：未命中以上任何一类 → 读取 `references/wenyan.md`，按信达雅三层结构展开翻译。

3. **输出结构**
   无论哪一流派，输出均包含以下模块（可根据风格指南适当调整比重与顺序）：

   - **原文**：完整呈现用户输入的古文。
   - **今解**：用现代汉语进行生动翻译或再创作，拒绝学术腔与论文体。
   - **意境 / 结构**：解读文字背后的情绪张力、卦象结构或韵律呼吸。
   - **生活映照**：将古文场景映射到现代生活（职场、社交、信息焦虑、情感、内卷等），让今人看见自己的处境。
   - **余响 / 留白**：不做封闭总结，留一句让人回味的话，或一个开放式问题。

4. **语气与质地约束**
   - 真而不硬，深而不玄，美而不艳，静而不空。
   - 短句为主，允许留白、断裂、空拍与重复，让文本有呼吸感。
   - 不堆砌注释，不考据，不进入"中心思想是——"的论文模式。
   - 拒绝心灵鸡汤、成功学、网络金句堆砌与假禅意。
   - 核心目标：让古人说现代人能懂的话，让今人看见自己的处境。

5. **保存产物**
   完成诠释后，将完整输出保存为 markdown 文件：

   - **目录**：`./output/guwen-translate/`
   - **命名格式**：`{YYYY-MM-DD}--{topic}__guwen.md`
     - `topic` 取典籍简称（如 `daodejing`、`shijing`、`yijing`、`jingangjing`、`lunyu`、`zhuangzi`、`sunzi`、`tanjing`）或原文前 4-6 字的拼音/中文，保持简洁。
     - 示例：`2026-05-18--daodejing__guwen.md`、`2026-05-18--tianxingjian__guwen.md`、`2026-05-18--lunyu-ren__guwen.md`
   - **操作**：使用 `mkdir -p ./output/guwen-translate/` 确保目录存在，然后写入文件。
   - **内容**：文件内容与 CLI 输出完全一致，包含所有模块（原文、今解、意境/结构、生活映照、余响/留白）。
   - **告知用户**：保存完成后，在回复末尾用一行小字提示文件路径，例如：
     > 已保存至 `./output/guwen-translate/2026-05-18--daodejing__guwen.md`

6. **特殊处理**
   - 若用户只给一句极短的话（如"大道至简"），不要强行拉长，保持简洁有力。
   - 若用户给出多段或多章，逐段处理，每段之间用分割线隔开，保持各自的"温度"与"节奏"。
   - 若用户同时提供了现代生活情境（如"我最近工作很焦虑，怎么看这句"），在生活映照部分优先回应该情境。

## 质量红线（禁止输出）

出现以下任何一种情况，视为执行失败，必须重写：

1. **学术腔 / 论文体**："本文旨在探讨...""综上所述，中心思想是...""从语言学角度看..."
2. **鸡汤 / 成功学**："你只要...就能...""成功的秘诀在于...""心态决定一切"
3. **网络金句堆砌**：用流行语、梗、emoji 泛滥来替代真正的理解
4. **假禅意 / 伪玄虚**："一切都是空""道法自然所以你要顺其自然"（空泛复述，无具体转译）
5. **错误典籍归属**：把《论语》句子说成《道德经》，或把《诗经》当成《楚辞》
6. **过度引申**：从一句古诗强行扯到宇宙人生大道理，失去文本锚点
7. **封闭总结**：以"总之""归根到底""本质上"收尾，消灭余响与留白
